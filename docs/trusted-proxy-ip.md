# 客户端 IP 与可信代理配置

登录、验证码、短信限流以及微信 H5 支付使用 `IpUtil.getClientIp` 解析客户端地址。默认只使用 HTTP 连接的直连地址，不信任请求携带的 `X-Forwarded-For` 或 `X-Real-IP`。

部署在反向代理或网关后面时，在各后端服务的共享配置中设置实际代理地址或 CIDR，例如：

```yaml
liteshop:
  security:
    trusted-proxies: ${TRUSTED_PROXY_CIDRS:}
```

`TRUSTED_PROXY_CIDRS` 可用逗号分隔多个地址，如 `10.0.1.10,10.0.2.0/24`。只填直接连接应用的代理及转发链中由自己管理的代理，不应将整个公网网段加入。入口代理应清除客户端传入的同名转发头，再写入真实转发链。

配置后从转发链右侧开始剥离可信代理，遇到首个不可信地址即作为客户端 IP。未配置或转发链无效时使用直连地址。若所有请求经过网关但未配置代理地址，限流会按网关地址聚合；上线前需按实际网络拓扑配置并核对登录、短信和支付请求日志。
